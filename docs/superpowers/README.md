# Historical Plans and Specs

Semua file di folder ini adalah snapshot historis dari rencana atau design decision sebelum implementasi final.

Dokumen ini bukan current truth. Jika isinya berbeda dengan implementasi terbaru, gunakan:

- `../framefield-overview.md` untuk product scope dan status;
- `../element-implementation.md` untuk kontrak package, route, metadata, dan preview;
- `../../library/sections/<slug>/design.md` untuk keputusan visual asset;
- `../documentation-audit.md` untuk perubahan scope dan alasan keputusan.

Plan/spec lama tidak perlu diedit saat implementation berubah, kecuali sedang menulis catatan sejarah. Plan baru wajib diberi status `Historical snapshot` setelah eksekusi selesai atau digantikan.
